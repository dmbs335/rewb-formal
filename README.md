# REWB Formal

Research-in-progress Lean 4 formalization of fixed-pattern, dynamically 2-use, single-register regular expressions with backreferences.

**Status:** The proposed soft-O(n^(25/13)) upper bound is a research conjecture/proof draft, not a kernel-verified theorem or a claimed published result. This public repository is intended for reproducible verification and correction. No optimality or novelty is asserted.
